# 错误范围与材料识别

接收学生写错的单词或句子、原题、学生答案、正确答案、一道或多道错题、作业/试卷/练习册照片，以及它们的组合。先找真实证据，再选错误类别；一题可能涉及多个错误。

## 从材料中提取什么

- 文字：对照学生表达与原题要求、给定答案及上下文，定位错误位置。
- 拼写：记录正确单词、学生拼法、字母差异、可能涉及的规律及难度相近的同类词。
- 语法：定位错误的句子成分和相关结构，核对原句语境。
- 词汇用法：核对错词与目标词的实际含义、词性、搭配和使用场景。
- 图片：尽可能读出原题、学生答案、题面给出的正确答案或批注、错误位置、原题题型、词汇难度、句子结构和上下文。图片中的明显上下文应优先用于判断错因。

照片中看不清的字、缺失的题干或无法确定的正确答案不能自行补造。如果这些缺口会改变判断，就先请用户补充。若学生答案也可能正确，先确认题意和语境。

## 至少识别这些错误类别

| 类别 | 常见情况 |
| --- | --- |
| 单词拼写 | 字母遗漏、多写、替换、顺序错误、双写、词尾变化、常见拼写规律、音形对应 |
| 词义与词汇使用 | 词义、近义词、反义词、词性、固定搭配、使用场景 |
| 名词与冠词 | 单复数、可数/不可数、a、an、the、零冠词、所有格 |
| 动词 | 主谓一致、动词形式、时态、助动词、情态动词及常见变化 |
| 形容词与副词 | 词性、比较级、最高级、修饰关系 |
| 介词、代词、连词 | in/on/at 等介词、主格/宾格、物主代词、指代、连词使用 |
| 句子结构 | 语序、疑问句、否定句、成分缺失、结构混乱 |
| 书写规范 | 大小写、标点、缩写、空格 |

类别只是内部定位工具，不要在最终给学生的结果里列出分类报告。
