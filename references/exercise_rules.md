# 专项练习生成规则

## 题型选择

依次考虑：用户明确要求的题型；最适合纠正该错误的题型；原题题型是否同样适合；一般默认题型。通常填空优先于选择，再考虑其他题型；但词义混淆更适合语境选择时，即使原题是翻译题也应选选择题。拼写错误默认用填空，给首字母，让学生亲手写出后面全部字母，而非只认词选择；用户明确要求整词练习时按其要求。

| 错误 | 优先练习方式 |
| --- | --- |
| 拼写 | 根据中文意思或明确语境，给首字母，补写后面全部字母 |
| 词义、近义词混淆 | 语境选择 |
| 固定搭配 | 填空或选择 |
| 冠词 | 语境填空，含零冠词 |
| 介词 | 语境填空或选择 |
| 主谓一致、时态 | 动词形式填空 |
| 代词 | 填空或选择 |
| 单复数 | 形式填空 |
| 句子结构 | 改错或排序 |
| 语序 | 排序或重组 |
| 大小写、标点、缩写、空格 | 改写或改错 |

## 拼写：给首字母，补全其余部分

拼写题默认只给目标单词的正确首字母，横线留出后面所有字母；答案仅写所填部分。例如 light 写成 lait，出“灯：l____”，答案 ight；waste 写成 wast，出“浪费：w----”，答案 aste。这样即使只漏了词尾 e，也要反复写完整的 -aste，而不是只填 e。相关词按同样方式出题，如 p----（paste）、h----（haste），答案均为 aste；选词仍要符合学生词汇难度或用户指定的词。不要把写错的字母当作提示。用户明确要求整词练习时才改为写完整单词。

若问题在字母组合与发音的对应，练习应让学生在多个相近词中反复填写首字母后的相同词块，如 -ight 或 -aste。另选一组常见同类词供学生观察：字母组合相同、对应读音相同，音节或词块尽量相近；不能只看拼写相似就把读音不同的词放在一组。优先给 3—5 个真实、难度合适的词；找不到足够可靠的例词时少给，不编造或塞入生僻词。需要标读音时先核准，不确定就不写音标。输出中明确写出这组同类词及共同的字母组合/读音线索，不要只把它们藏在练习或参考答案里。

## 词义：用语境区分

把“使用”写成 rent 时，重点区分 use（使用）与 rent（租用），可加入 borrow、lend 作相关辨析。用“借用笔”“使用电脑”“租车”等不同场景出题，避免连续十道同义的汉译英。与原错直接相关的词获得更多训练；其他词只用于辨析，不假定学生也混淆它们。选择题的干扰项必须在该语境下确实不合适，正确选项位置应变化。

## 冠词和多情况考点

漏写 the 时，以 the 为重点，同时出现 a、an 和零冠词。十题可以大致安排 the 5、a 2、an 1、零冠词 2；这是可调整的示例，不是配额。若学生连续出现不同冠词错误，可增加其他冠词情况的覆盖。不能让十题答案全是 the。be 动词、介词、主谓一致、代词等也遵循“重点训练 + 有用的对照”，不让答案机械重复。

## 难度、数量与变化

- 难度依次参考用户指定、原题词汇、图片词汇、原题句式、上下文、用户额外给出的词汇。词汇难度是重要依据；年级不能单独决定固定词汇等级。
- 仅有“hope 写成 hop”等少量信息时，选常见、易懂的同规律词。宁可略简单，也不要为了“进阶”突然提高难度。
- 默认**总共 10 道**。用户指定数量时严格遵守。多个错误共用这 10 道，按重点分配；只有用户明确要求时才对每个错误分别出指定数量。
- 默认基础与进阶约 2:1，十题可用基础 7、进阶 3。知识点简单时可多给基础题；用户指定难度时优先遵守。
- 基础题直接巩固，进阶题在相同考点下改变人物、场景、词汇或表达。避免十题一样、只替换一个词、机械重复句型；也不能为求变化而转移考点、引入无关语法或陡增难度。

## 输出前逐题核查

1. 题数正确，核心错误得到重点训练，相关情况适当覆盖。
2. 没有机械重复、大量相同答案或固定的选择题正确选项位置。
   拼写题为巩固同一词块而多次填写相同答案时，不受“大量相同答案”限制；仍应变化词语或语境。
3. 词汇和句式难度符合原题或用户要求，没有无关复杂语法。
4. 英语和语境自然，题意明确，题型确实训练目标。
5. 每题答案明确且正确；可能多解时补足限制语境，或列出所有可接受答案。
6. 拼写题默认只给正确首字母，留其余字母为空，答案与空格对应；若训练音形对应，另有一组字母组合、读音和音节/词块确实相符的同类词；基础/进阶划分与实际难度一致。

检查失败应修改题目或答案后再输出。格式校验脚本无法替代以上语义检查。
